# Rust & Barter

A small merchant-trading game whose world lives in a NEAR smart contract. There are three towns and four goods. Prices move with each merchant's stock and with daily demand, so buying low in one town and selling high in another is the whole game. Players can also invest in a town's merchant and earn a share of its trading spread. Rival NPC traders work the same roads.

**Testnet only.** Coins and goods are game points with no real-world value. They can't be bought, sold or withdrawn, and there is no wagering.

Submitted to the NEAR hackathon (games track). Our other entry is **Usage vs Price**, a reproducible on-chain data thesis (thesis track): repo link TBD.

## What's on-chain

`contract/` is Rust, near-sdk 5.29, built with cargo-near 0.22.

| Method | What it does |
|---|---|
| `join` | Start with 1,000 coins in Millbrook |
| `travel(town)` | Move to another town for 30 coins |
| `buy(good, qty, max_total)` / `sell(good, qty, min_total)` | Trade with the town merchant. The limits protect you if the price moves first. |
| `invest(amount)` / `divest(town)` / `claim(town)` | Stake coins in a merchant. Its stock targets rise, and you get 50% of its spread, pro rata (MasterChef-style accumulator). |
| `mt_transfer(...)` | Give goods to another player (NEP-245-style) |
| `declare_bankruptcy` | Broke with nothing left? Restart on 600 coins. Your bankruptcy count is public. |
| Views | `day`, `config`, `quotes(town)`, `get_player(s)`, `get_merchant`, `pending_dividends`, `mt_balance_of` |

Events are NEP-297 logs (`nep245` mint, burn and transfer, plus `rust_and_barter` join, travel, invest, divest and bankrupt), so any indexer can rebuild the game history.

### Pricing (`contract/src/pricing.rs`)

- `mid = clamp(base · ref_stock · demand% / (100 · stock), base/4, base·4)`. Price rises as stock falls.
- Buying pays mid +5% and selling receives mid −5%. Large orders walk the price one unit at a time.
- Daily demand comes from `sha256("rb" ‖ day ‖ town ‖ good)` and runs from 80% to 130%. Every client can recompute it, and nobody can change it.
- Each day a merchant restocks 1/5 of the way back to its target. Investment raises the target by up to +100%.

## Web client (`web/`)

React + Vite. `web/src/pricing.ts` is a line-for-line mirror of `pricing.rs`, and `web/src/sim.ts` mirrors the contract's state machine. The mirrors are checked by tests:

- `contract/tests/vectors.json` holds 192 cases generated by the Rust code. `pricing.test.ts` asserts that the TypeScript gives identical results.
- `sim.test.ts` replays the sandbox scenario from `contract/tests/test_basics.rs` and gets the same final balance (1,312 coins).

**Practice mode** runs the full rules in the browser with no wallet, so anyone can play the demo. Testnet mode (in progress) sends the same actions to the deployed contract.

NPC rivals (`web/src/npc.ts`) are rule-based on purpose: a hauler that runs the best route, an investor who stakes in merchants, and a drifter who mostly gets lost. Each one says a line from a template on every move. `npx tsx scripts/balance.ts 60 4` fast-forwards 60 days to check the game balance.

## Run it

```bash
# contract
cd contract
cargo test                           # 13 unit tests + sandbox integration test
cargo near build non-reproducible-wasm

# web
cd ../web
npm ci && npm test && npm run dev
```
