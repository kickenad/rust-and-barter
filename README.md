# Rust & Barter

A small merchant-trading game whose world lives in a NEAR smart contract. There are three towns and four goods. Prices move with each merchant's stock and with daily demand, so buying low in one town and selling high in another is the whole game. Players can also invest in a town's merchant and earn a share of its trading spread. Rival NPC traders work the same roads.

**Live on NEAR testnet:** [`rustbarter-8562c6.testnet`](https://testnet.nearblocks.io/address/rustbarter-8562c6.testnet) (game day = 30 seconds).

**Testnet only.** Coins and goods are game points with no real-world value. They can't be bought, sold or withdrawn, and there is no wagering.

Entry to the NEAR hackathon (games track). Per hackathon rule Q-015, our other (and only other) entry is **Usage vs Price**, a reproducible on-chain data thesis (thesis track): repo link TBD.

## What's on-chain

`contract/` is Rust, near-sdk 5.29, built with cargo-near 0.22.

| Method | What it does |
|---|---|
| `join` | Start with 1,000 coins in Millbrook |
| `travel(town)` | Move to another town for 30 coins. You arrive at the start of the next game day and cannot trade on the road. |
| `buy(good, qty, max_total)` / `sell(good, qty, min_total)` | Trade with the town merchant. The limits protect you if the price moves first. Your cart holds 15 units in total. |
| `invest(amount)` / `divest(town)` / `claim(town)` | Stake coins in a merchant. Its stock targets rise, and you get 50% of its spread, pro rata (MasterChef-style accumulator). |
| `mt_transfer(...)` | Give goods to another player (NEP-245-style) |
| `declare_bankruptcy` | Broke with nothing left? Restart on 600 coins. Your bankruptcy count is public. |
| Views | `day`, `config`, `quotes(town)`, `get_player(s)`, `get_merchant`, `pending_dividends`, `get_stake(s)`, `mt_balance_of` |

Events are NEP-297 logs (`nep245` mint, burn and transfer, plus `rust_and_barter` join, travel, invest, divest and bankrupt), so any indexer can rebuild the game history.

### Pricing (`contract/src/pricing.rs`)

- `mid = clamp(base · ref_stock · demand% / (100 · stock), base/4, base·4)`. Price rises as stock falls.
- Buying pays mid +5% and selling receives mid −5%. Large orders walk the price one unit at a time.
- Daily demand comes from `sha256("rb" ‖ day ‖ town ‖ good)` and runs from 90% to 115%. Every client can recompute it, and nobody can change it.
- Each day a merchant restocks 1/5 of the way back to its target. Investment raises the target by up to +100%.

## Web client (`web/`)

React + Vite. `web/src/pricing.ts` is a line-for-line mirror of `pricing.rs`, and `web/src/sim.ts` mirrors the contract's state machine. The mirrors are checked by tests:

- `contract/tests/vectors.json` holds 192 cases generated by the Rust code. `pricing.test.ts` asserts that the TypeScript gives identical results.
- `sim.test.ts` replays the sandbox scenario from `contract/tests/test_basics.rs` and gets the same final balance (1,270 coins).

Two modes, same UI:

- **Practice** runs the full rules in the browser with three rival traders. You choose when the day ends.
- **Play on NEAR testnet** needs no wallet. The page creates a throwaway testnet account through NEAR's public faucet (`helper.nearprotocol.com`) and keeps its key in the browser's local storage. Every move is then a signed transaction to the contract, with a NearBlocks link. Views go over public JSON-RPC (FastNear, with fallbacks). Code: `web/src/chain.ts`.

NPC rivals (`web/src/npc.ts`) are rule-based on purpose: a hauler that runs the best route, an investor who stakes in merchants, and a drifter who mostly gets lost. Each one says a line from a template on every move. `npx tsx scripts/balance.ts 60 4` fast-forwards 60 days to check the game balance. Travel time and the 15-unit cart keep the best rival at about 5× its starting coins after 60 days (an early build without them let it reach about 110×). `balance.test.ts` keeps it between 2× and 10×.

`npx tsx scripts/npc-testnet.ts 10` runs the same three NPCs as real testnet accounts. Each decision is made on a local mirror of chain state (`web/src/mirror.ts`) and then sent as a signed transaction.

## Run it

```bash
# contract
cd contract
cargo test                           # 15 unit tests + sandbox integration test
cargo near build non-reproducible-wasm

# web
cd ../web
npm ci && npm test && npm run dev    # open http://localhost:5173 (add #testnet for testnet mode)

# end-to-end against the deployed testnet contract (creates a faucet account; keys go to ../../secrets/, never printed)
npx tsx scripts/e2e-testnet.ts
# headless browser run of both modes (needs puppeteer-core and Chrome; serve with `npx vite preview --port 4173`)
node scripts/browser-e2e.mjs
```

Deploy your own copy: `cargo near build non-reproducible-wasm`, then `near contract deploy <account> use-file target/near/rust_and_barter.wasm with-init-call new json-args '{"day_seconds":30}' ...`, and set `VITE_CONTRACT=<account>` for the web client.
